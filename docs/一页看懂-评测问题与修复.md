# 一页看懂：评测发现的问题，现在什么状态

> 这份是给"不想读技术细节"的人看的。技术版在 [agent-eval-diagnosis-2026-10-29.md](agent-eval-diagnosis-2026-10-29.md)。

---

## 三句话

1. **听得懂你说什么** —— 这部分一直是好的（98% 以上）。
2. **以前不会替你记、也找不出你要的岗位** —— 现在「记」修好了，「找」还没修好。
3. 没修好的那条，卡在一个很具体的地方：**它在挑岗位之前，先把"你不够格"的岗位全删了**，而你想看的往往正是那些。

---

## 一个比喻，说明核心毛病

你要找一个招聘助理帮忙。

**你**：帮我找产品经理的岗位。
**助理**：翻了翻你的简历，发现你没做过产品，把库里所有产品岗**直接从桌上拿走了**，
然后把剩下的 Java 岗按"和你简历像不像"排了个序，递给你 6 个。

问题不是他排序排错了，是**他把"你不合适"当成了"你不用看"**。

这两件事不一样：

| | 意思 | 该怎么做 |
|---|---|---|
| 你不合适 | 投了大概率没回音 | 告诉你「方向对，但差在哪」 |
| 你不用看 | 这不是你要的方向 | 直接从结果里拿掉 |

旧的代码把这两件事合并成了同一个判断，所以只要简历不匹配，岗位就消失——
哪怕你明确说了「我想看产品岗」。

## 五个问题，逐个说状态

| # | 问题（说人话） | 现在 |
|---|---|---|
| 1 | 你说「记住了」，它答应了，但其实什么都没存 | ✅ **修好了**。现在真的写进库，回复末尾会写「已写入画像：目标城市 → 佛山」 |
| 2 | 你说「找实习」，它给你的全是社招 | ✅ **修好了**。原来代码里写死了"不要实习"，现在跟着你的设置走。可选岗位从 12 个变成 39 个 |
| 3 | 你说「找产品经理」，它给你 Java 岗 | ❌ **没修好**。产品岗在排序之前就被删了。要改流程，不是改参数 |
| 4 | 有些偏好说了它记不住（比如"一定要双休""优先看大厂"） | ✅ **修好了**。有 4 类偏好以前**在代码层面就不可能被记住** |
| 5 | 它会翻出很久以前的事，而且每次都要翻三条出来 | ⬜ **还没动**。这条我没改，排在下一批 |

## 「修好了」的证据是什么

不是"我觉得改对了"，是拿同一套题重考：

| 考试内容 | 改之前 | 改之后 |
|---|---:|---:|
| 该记住的话，记住了几句 | 8 / 13 | **13 / 13** |
| 不该记的话，误记了几句 | 0 句 | 2 句（但那 2 句**都没写进库**，只是标记成"待确认"） |
| 你说完"记住了"，库里真的变了吗 | 0 条变化 | **写入 + 历史留痕** |
| 能进入候选池的岗位 | 12 个 | **39 个** |
| 「找产品经理」能搜到几个产品岗 | 0 / 4 | 0 / 4（没变） |

最后一行没变，就是因为第 3 条没修。这两件事是同一件事：产品岗和实习岗都是被"删"掉的，
实习岗因为改了设置能进来了，产品岗因为技能不匹配，还是进不来。

---

## 为什么"能进入候选池的岗位"从 12 变成 39，还是搜不到产品岗

因为名额只有 6 个，而这 6 个是按「简历匹配分」排的。

现在的排名（意图=后端实习）：实习岗排在第 15、16、22 名。
前 6 名被 5 个"完全符合简历"的岗位占满——分数 80、70、62、40、33。
即使"方向相关度"这一项给实习岗加了分，也只有 3 分左右，跨不过 24 分的差距。

**名额分配的方式错了，不是分数算错了。**

---

## 接下来要改什么（一句话）

改成「先按方向捞一批，再在里面排优先级」，并且把结果分三栏：

```
第一栏：方向对 + 你能投        ← 现在只有这一栏
第二栏：方向对 + 你还投不进     ← 新的，会写清楚"差在哪"
第三栏：（方向不对的，不显示）
```

第二栏就是产品岗该出现的地方：不是假装你能投，而是告诉你
「这个方向有 4 个岗位，你的简历缺 X，要投的话先补这里」。

## 你可能想知道的三个小问题

**为什么"多记了 2 句"也算问题？**
考试是把"该记的"和"不该记的"都算分。多记的两句：一句是你说了"2028 届本科"，
它同时记了学历（其实是对的，是考题漏了）；另一句是"帮我找佛山的岗位"里的"佛山"，
它标记成了"待确认"、没写进库，而且会在回复里问你「要长期按这个筛吗」。

**评测跑一次会不会把数据搞乱？**
会。以前不会，因为记忆根本不写；现在会了。所以我跑完已经手工还原到原样
（3 个画像槽位、4 条历史、9 个会话）。以后跑评测要先备份。

**这些改动我需要做什么？**
不用。服务已经重启，刷新页面就能用。唯一的变化是：以后你说"记住了"，
它会真的记，并且告诉你记成了什么。
